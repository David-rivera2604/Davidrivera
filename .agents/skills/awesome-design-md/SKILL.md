# awesome-design-md

Reference library. Each brand lives at `design-md/<brand>/DESIGN.md` (relative to this skill folder).

## How to use

1. Identify the brand the user wants (e.g. "estilo Linear" -> `design-md/linear.app/DESIGN.md`). List folders with `ls design-md` if unsure of the exact name (e.g. `linear.app`, `mistral.ai`, `x.ai`, `opencode.ai`, `together.ai`).
2. Read that brand's `DESIGN.md` fully before writing any code.
3. Take tokens (colors, type scale, spacing, radii, shadows) and component rules from it; do not copy the brand's logo, name, copy or imagery.
4. If the user names several brands, read each and say which traits you take from which.
5. For production-quality frontend work, combine with the `design-taste-frontend` skill; the DESIGN.md sets the visual language, taste-skill sets the quality bar.
