# Davidrivera

Portafolio / CV de José David Rivera Trejos — sitio estático con información profesional, proyectos y formas de contacto.

Este repositorio contiene una página estática (index.html) que sirve como currículum y portafolio personal. El sitio está pensado para desplegarse tal cual en GitHub Pages desde la rama `main` (sitio de proyecto) o, si prefieres un sitio de usuario, renombrando el repositorio a `davidrivera.github.io`.

Contenido principal

- index.html — Página principal (CV y portafolio). Ábrela directamente en el navegador o usa un servidor estático local.
- portafolio-david-rivera-deploy (1).zip — Archivo ZIP con una versión desplegable del portafolio.

Cómo ver el sitio localmente

1. Clona el repo:
   git clone https://github.com/David-rivera2604/Davidrivera.git
2. Entra en la carpeta y ejecuta un servidor local (ejemplo con Python):
   cd Davidrivera
   python3 -m http.server 8000
3. Abre http://localhost:8000 en tu navegador y haz clic en `index.html` si no se abre automáticamente.

Despliegue con GitHub Pages

- Para publicar desde esta repo como sitio de proyecto: en la configuración del repositorio (Settings → Pages) selecciona la rama `main` y la carpeta `/ (root)`.
- Para publicar como sitio de usuario con la URL `https://davidrivera.github.io` necesitas que el repositorio se llame exactamente `davidrivera.github.io`.

Tecnologías

HTML y CSS (sitio estático). Imágenes y recursos principales están embebidos en `index.html` como data URIs para simplificar el despliegue.
